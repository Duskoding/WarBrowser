The site from gui/, running twice as if on two computers. The pretend server in the middle follows the same room rules as server.js and runs the real games from src/games/.

  1. Click a game in Player 1's window to create a room.
  2. Type the room code into Player 2's window and click Join.
  3. Play in both windows.
