# WarBrowser
War played on two different computers

## Project: Live War

Two people, in two browsers, play War against each other live. Each flip shows up on both screens at once. The rules run on your card library, on a server. One feature calls an AI model through its API: for example, a commentator that describes each round.

You choose the language and tools. Before you build, write a spec that covers how the pieces fit together, which War rules you're using, and who on the team owns which part.
